# Mohanpur Construction

Home construction expense tracker for **Surjendu, Madhumita, Subhendu & Mamata**.

Track credits, debits, and material costs (rod, cement, sand, bricks, labour, tiles, pipe, electricity, etc.) with live charts — backed by Google Sheets, hosted on GitHub Pages.

## Quick start

1. Open `index.html` in a browser — PIN **`2026`** (demo mode).
2. Follow **[SETUP-GUIDE.md](SETUP-GUIDE.md)** to connect Google Sheets and publish on GitHub.

## Files

| File | Purpose |
|------|---------|
| `index.html` | Website UI |
| `Code.gs` | Google Apps Script backend (paste into Sheets) |
| `SETUP-GUIDE.md` | Full setup instructions |
| `manifest.json` / `service-worker.js` | PWA (install on phone) |
| `photos/` | Member photos |
| `icons/` | App icons |

Based on the [hisab-khata](hisab-khata/) family fund tracker pattern.
